So what I did differently in this shader is that I first added a noise node to the waves in order to see what happens. I figured out that it gives them a cool pixel gradient with the step node. I then tried to increase the power of the wave, but that just made it glow somehow. I liked it, though and decided to leave it in. I then wanted the wave to appear more like their color instead of losing its contrast. I just put an inverted wave multiplied with the original colour and texture of the material, so it only appears this glowing bright blue color.
